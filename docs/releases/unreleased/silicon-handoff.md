# Silicon layout review

Circuit Weaver can render a core, shuttle wrapper or full die from GDSII or OASIS through the CLI, Python and MCP. The handoff reviewer checks the physical top and the evidence for a selected shuttle run, reports missing items, and can package a complete review set with SHA-256 hashes. Install the optional `silicon` extra to enable KLayout. [Commands and evidence format](../../silicon-handoff.md)
